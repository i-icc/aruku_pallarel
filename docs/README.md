### デプロイ URL について

* 今回作成した「あるく🚶パラレル」は位置情報の取得と、バックグラウンド実行、プッシュ通知がサービスのコアとして必要なため、Web での公開をすることが叶いません。
* iOS 限定にはなってしまいますが、app store connect の外部テスターとして招待することで動くものは共有することは可能ですので。もしそちらの方法でよろしい場合は申請フォームのメール、もしくはディスコードコミュニティにてご連絡をいただけると幸いです。
