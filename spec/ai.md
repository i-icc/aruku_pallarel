# エージェント設計（ADK / LLM）

## 使用モデル
- Gemini 3 Flash Preview（Google AI / Vertex AI）
- Vertex AI で Gemini 3 preview を使う場合は `GOOGLE_CLOUD_LOCATION=global` を前提とする

## 目的
- 未踏地点の体験を言語化し、散歩後の余韻をつくる
- ルート案内や意思決定の代行はしない

## 入力（最小）
- 候補地点の緯度経度

## 出力形式（JSON）
```json
{
  "message": "この道、静かで木陰が多いかも。午後に歩くと心地よさそう。"
}
```

## 生成ルール
- 1〜2文、短く余白を残す
- 断定を避け「かも」「〜そう」などの表現を使う
- ナビ/指示/危険行為の促進はしない
- 具体的な住所は不要（緯度経度で十分）
- ユーザーの現在行動を変える提案はしない（“次回”を前提にする）

## URL生成
- URL は Job 側で組み立てる（Google Maps の DMS 形式）

## 失敗時の扱い
- 生成に失敗した場合は通知せず、再試行で回復する
