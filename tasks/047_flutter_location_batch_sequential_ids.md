# 位置情報バッチを連番ドキュメントで更新

## 背景 / 事象
- `locations` が保存されない/視認しづらい
- 64件ごとに新規ドキュメント作成ではなく、64件までは同一ドキュメントを更新し続けたい
- ドキュメントIDは `1,2,3,...` の連番にしたい

## 目的
- 位置更新時の保存状態を分かりやすくする
- 64件ごとの区切りが把握しやすいようにする

## 方針
- `locations/{batchId}` を数値連番で管理する
- `count` を持ち、64件未満の間は同一ドキュメントに追記する

## 要件
1. `locations` のドキュメントIDが `1,2,3,...` になる
2. 1ドキュメントあたり最大64件まで保持し、超過分は次のIDへ
3. 位置更新ごとに即時保存される

## テスト
- 位置更新ごとに `locations/1` の `points` が増えていくこと
- 64件を超えたら `locations/2` が作成されること
