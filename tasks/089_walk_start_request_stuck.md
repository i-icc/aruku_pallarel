# Start Walk が送信されずロードが止まる問題の調査/修正

## 背景 / 事象
- Start を押すとローディングが止まらず、散歩開始のリクエストが送信されない
- ネットワーク監視では /v1/walks が飛んでいない

## ゴール
- Start を押すと必ず /v1/walks へリクエストが送られる
- 位置取得やトークン取得に失敗しても UI が固まらず、ユーザーへ通知される
