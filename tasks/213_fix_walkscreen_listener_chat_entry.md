# 散歩中マップの Riverpod listen 例外とチャット導線修正

## 背景
- 散歩中マップ起動時に `ref.listen` が initState で呼ばれ例外が発生
- チャットは散歩(地図)からのみ遷移する仕様だが、ホームにも導線が残っている

## ゴール
- 散歩中マップの初期化時例外が発生しない
- チャット導線は散歩中マップのみから辿れる

## ToDo

- [ ] ホームのチャットショートカットを削除する
- [ ] 散歩中マップにチャット遷移ボタンを追加する

## 受け入れ条件
- 散歩中マップ起動で例外が出ない
- ホームにチャットボタンが表示されない
- 散歩中マップからチャットへ遷移できる

## テスト
