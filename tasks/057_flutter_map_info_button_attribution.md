# マップ左下の Info ボタンで提供元情報を確認できるようにする

## 背景 / 事象
- アトリビューションをマップ上に常時表示しない方針に変更
- 規約対応として、地図画面から情報を確認できる導線が必要

## 目的
- 散歩中/履歴詳細のマップ左下に小さな Info ボタンを追加する

## 方針
- Info ボタンタップでボトムシートを開き、テーマ別の提供元情報を表示する

## 要件
1. 散歩中マップの左下に Info ボタンが表示されること
2. 履歴詳細マップの左下に Info ボタンが表示されること
3. Info ボタンから提供元情報が確認できること

## テスト
- 散歩中/履歴詳細で Info ボタンが表示される
- Info ボタンから Map Info を開ける
