# 位置履歴取得と未踏判定ユーティリティ

## 背景 / 事象
- Job で候補点の未踏判定を行うため、位置履歴の取得と距離計算が必要

## 目的
- locations のフラット化と軌跡ライン距離計算を共通ユーティリティとして用意する

## 方針
- `locations/{batchId}` を `index` 順で取得し、points を時系列に整列する
- 軌跡ライン（点列）と候補点の最短距離を計算する
- 10m 以内なら既踏扱いとする

## 要件
1. walkId から locations を一括取得して時系列の配列に変換できる
2. 軌跡ラインへの最短距離計算（点-線分）を実装する
3. 未踏判定（距離 <= 10m）を返す関数を用意する
4. 距離計算のユニットテストを追加する

## テスト
- サンプル座標で未踏/既踏判定が期待通りになることを確認する
