# 未ログイン時の初期遷移をログイン画面へ固定

## 背景
- ログイントークンがない状態でもホーム画面から開始される
- AuthGuard の context 取得失敗時にガードが素通りする可能性

## ゴール
- 未ログイン時は必ずログイン画面に遷移する
- ログイン画面の自動遷移は有効なトークンがある場合のみ

## 対象範囲
- AuthGuard
- LoginScreen の自動遷移判定

## 非対象
- 認証方式の変更
- UI デザインの変更

## ToDo

## 受け入れ条件
- ログアウト状態で起動するとログイン画面になる
- トークン無効時はホームに遷移しない

## テスト
- ログアウト状態の起動
- ログイン済みの起動
