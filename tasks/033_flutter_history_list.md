# 履歴一覧の表示

## 背景 / 事象
- 仕様では過去の散歩履歴を一覧表示できる
- 現状は履歴画面が未実装

## 目的
- Firestore の walk 一覧を読み取り、履歴画面に表示する

## 方針
- `users/{uid}/walks` を `startedAt desc` で取得する
- 読み取り専用の UI を用意する

## 要件
1. Home から履歴画面へ遷移できる
2. `status` と `startedAt`/`finishedAt` を表示する
3. 空のときは空状態を表示する
4. 1 件選択で詳細画面へ遷移する

## テスト
- 散歩終了後に履歴に表示されること
