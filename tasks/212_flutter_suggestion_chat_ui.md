# 提案チャット画面を dm_chat 風に実装する

## 背景
- チャット画面がプレースホルダのままで、提案内容を閲覧できない
- dm_chat 風の「読みやすい会話 UI + 自然なスクロール挙動」に寄せたい

## ゴール
- 提案メッセージがチャット形式で表示される
- Map の選択ピンとチャットが相互連動する
- dm_chat の UI/挙動エッセンスを取り込んだ読みやすい体験になる

## 依存
- `selectedSuggestId` / suggests 取得は 211 で追加済みであること

## dm_chat の実装エッセンス（このタスクで取り込む要素）
- ListView を `reverse: true` で構成し、最新が下に見える会話体験
- 画面下端付近にいる時だけ自動スクロール（閾値 100px 前後）
- 空状態（アイコン + テキスト）
- バブル UI（角丸 18px・薄い影・白背景）
- タイムスタンプ表示（送信時刻を簡易整形）
- URL を検出し、リンクプレビューカードを表示（画像 + タイトル）
- SafeArea 付きの下部固定エリア（入力欄は将来拡張用に非活性 or 非表示）

## 対象範囲
- チャット画面 UI（メッセージ一覧/ハイライト/空状態/エラー/ロード）
- チャットの provider（Firestore から `chat` を購読）
- Map 連動（`selectedSuggestId` の反映）

## 非対象
- ユーザー送信の実装
- 返信/リアクション/既読などの高度機能

## 仕様参照
- `spec/ux.md`（チャットで提案を閲覧/URL を開く）
- `spec/data-model.md`（chat/suggests スキーマ）

## プラン
1. chat 取得
   - active walkId から `users/{userId}/walks/{walkId}/chat` を購読
   - `createdAt asc` で取得し、表示モデルに変換
   - `suggestId` を保持してピン連動に使う
2. UI レイアウト
   - 背景色を薄いグレー系にして会話 UI を強調
   - ListView `reverse: true` + パディング（上下 16px 程度）
   - 空状態/ローディング/エラー（Retry）を用意
3. メッセージ表示
   - 1件ずつバブル（角丸/影/余白）
   - 送信者ラベルは `system` なら固定ラベル、ユーザーは非表示（現状 system のみ）
   - タイムスタンプを小さく表示
4. URL プレビュー
   - メッセージ本文から URL を抽出
   - プレビューカード（画像 + タイトル）を表示しタップで外部ブラウザ
   - プレビューの読み込み中はプレースホルダ
5. スクロール挙動
   - 画面下端付近なら自動スクロール
   - そうでない場合はユーザー操作を尊重
6. ピン連動
   - `selectedSuggestId` と一致するメッセージをハイライト
   - メッセージタップで `selectedSuggestId` を更新
   - Map 側で選択変更が起きたら該当メッセージへスクロール
