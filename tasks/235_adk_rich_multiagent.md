# ADK のサブエージェント構成で提案文をリッチ化

## 背景
- ADK の提案文が単発の出力に寄っており、質感や余韻が薄い
- サブエージェントを活用して観察/質感/余韻を分担させたい

## ゴール
- サブエージェントで要素を分解し、合成して 1〜2 文の提案文を出す
- 出力形式（JSON）は維持する

## 対象範囲
- `spec/ai.md`
- `src/backend/sanpo-agent/sanpo_agent/agent.py`

## 非対象
- API 仕様の変更
- ジョブ/FCM/Firestore の追加実装

## 受け入れ条件
- ADK の最終出力が `{ "message": "..." }` 形式を保つ
- 1〜2 文で、断定を避けた日本語の提案文になっている
- サブエージェントの成果を合成する構成になっている
