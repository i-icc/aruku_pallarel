# ADK エージェント定義をファイル分割

## 背景
- 1 ファイルに複数エージェント定義が集約されており見通しが悪い
- サブエージェントごとに責務を分離して保守性を上げたい

## ゴール
- 各エージェントを個別ファイルに分割する
- ルートエージェントは合成のみを担当する

## 対象範囲
- `src/backend/sanpo-agent/sanpo_agent/agent.py`
- `src/backend/sanpo-agent/sanpo_agent/agents/`

## 非対象
- 出力仕様や API の変更
