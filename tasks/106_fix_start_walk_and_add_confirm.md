# 散歩開始の修正と確認モーダル (Task 106)

## 背景
- 「散歩する」ボタンを押してもローディングのまま動かない（散歩が開始されない）現象が報告された
- 散歩開始時にも、終了時と同様に確認モーダルを表示してワンクッション置きたい

## ゴール
- 散歩開始の不具合（無限ローディング）の原因を特定し修正する
- 散歩開始ボタンを押したときに `AppConfirmDialog` を表示する
- 「散歩を始める」で実際に開始処理を行う
