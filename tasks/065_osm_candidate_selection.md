# 候補点選定と OSM 最寄り道路連携

## 背景 / 事象
- 候補点の最寄り道路取得（OSM/OSRM 連携）が未実装
- 未踏判定の 3 回リトライを組み込みたい

## 目的
- Job 内で候補点選定 → OSM 最寄り道路取得 → 未踏判定 → リトライを完結させる

## 方針
- startLocation と currentLocation から直径円を作り、円内ランダムに候補点を生成する
- OSM に `lat` / `lon` を渡して最寄り道路座標を取得する
- 既踏なら再選出し、最大 3 回で打ち切る
- OSM エラーや 3 回失敗時は request を failed に更新する

## 要件
1. 候補点生成ロジックを実装する
2. OSM クライアントを用意し、最寄り道路座標を取得できる
3. 既踏判定が true の場合は再選出し、最大 3 回で打ち切る
4. 3 回失敗または OSM エラー時は `requests.status=failed` を記録する
5. ローカル用に OSM スタブの起動手順または簡易実装を用意する

## テスト
- OSM スタブで 3 回リトライすることを確認する
- エラー時に `requests.status=failed` が記録されることを確認する
