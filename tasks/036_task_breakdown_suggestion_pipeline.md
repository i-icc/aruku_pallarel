# 提案生成パイプラインのタスク分解

## 背景 / 事象
- 提案生成フローの仕様はあるが、実装タスクが細分化されていない
- Backend/Job/OSM/ADK/FCM の担当範囲が広く着手しづらい

## 目的
- 提案生成パイプラインをスモールステップで実装できるよう、具体タスクを起票する

## 方針
- `spec/system.md` / `spec/ai.md` / `spec/data-model.md` / `spec/api.md` を再確認する
- Job/OSM/ADK/Firestore/FCM を分割して段階的に検証できる粒度にする

## 要件
1. パイプラインを構成する要素ごとにタスクを分割する
2. 各タスクに「背景/目的/方針/要件/テスト」を記載する
3. 小さな動作確認単位（例: 位置履歴取得のみ、ADK 呼び出しのみ）で切る
4. `tasks/PROGRESS.md` に優先順位付きで追加する
5. 仕様の不足があれば `spec/` を先に更新し、その上でタスクを起票する

## テスト
- 各タスクに検証手順が含まれていること
