# チャットのハーフモーダル化とピン/メッセージ連動強化

## 背景
- チャットをハーフモーダルで表示し、マップを見ながら提案を確認したい
- チャット一覧から該当する街灯ピンへフォーカスできるようにしたい
- ピンをタップしたときにメッセージ内容を地図上で確認できるようにしたい

## ゴール
- チャットがハーフモーダルとして表示され、マップが背面に残る
- メッセージタップで該当する街灯ピン位置にフォーカスし、選択状態になる
- ピンタップでピン直上にメッセージ内容のポップアップが表示される

## 依存
- 211: 散歩中マップに提案ピンを表示する
- 212: 提案チャット画面を dm_chat 風に実装する

## 対象範囲
- 散歩中マップ画面のチャット導線/表示
- チャット一覧とピン選択の相互連動
- ピン上のメッセージポップアップ

## 非対象
- チャット送信機能の追加
- 履歴画面の改修（必要なら別タスクで対応）

## テスト
