# Flutter で一定移動時に提案リクエストを送信する

## 背景 / 事象
- フロントエンドで提案リクエストを送る実装が未対応

## 目的
- 散歩中に一定距離・一定時間の条件を満たしたら提案リクエストを送信する

## 方針
- 位置更新ごとに移動距離を加算し、閾値を超えたら API を呼ぶ
- 直近の `result: ok` を基準にクールダウンを判定する

## 要件
1. `POST /v1/walks/{walkId}/suggestions:request` を呼べる
2. 250m 以上の移動と 5 分経過でリクエストする
3. `result: ok` の場合に距離/時間の基準をリセットする
4. エラー時はログまたは状態に記録する

## テスト
- 散歩中に 250m 以上移動するとリクエストが送信されること
- 5 分未満は送られないこと
