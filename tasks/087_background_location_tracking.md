# バックグラウンド位置取得が止まる問題の調査/修正

## 背景 / 事象
- 実際の散歩中、バックグラウンドで位置更新が止まる
- アプリ復帰時に位置が瞬間移動したように見える

## ゴール
- バックグラウンドでも一定間隔で位置更新が継続する
- 復帰時に不自然な移動が発生しない

## ToDo
- [ ] iOS の権限状態（When in Use / Always）と Background Modes を再確認する
- [ ] Locus の状態ログ（enabled/isMoving/last location）を取得し、停止タイミングを特定する
- [ ] バックグラウンド遷移時の Locus start/stop が意図せず発火していないか確認する
- [ ] Firestore の locations 書き込みが止まる時刻を特定し、OS 側制限かアプリ側停止か切り分ける
- [ ] 必要なら Locus の設定（distanceFilter/notification など）を見直す
- [ ] 実機で 5〜10 分バックグラウンド検証を行い、差分を記録する

## 受け入れ条件
- バックグラウンド中も位置更新が継続し、Firestore に記録される
- 復帰時に極端な位置の飛びが発生しない
