# フォントの役割別カスタマイズ

## 背景
- UI のフォントを役割に応じて使い分けたい
- 指定された 3 種のフォントを用途別に反映する

## ゴール
- ボタン/頻出 UI に M PLUS Rounded 1c が適用される
- 会話/メッセージ系テキストに Zen Maru Gothic が適用される
- システム/設定系の見出しに Kosugi Maru が適用される
