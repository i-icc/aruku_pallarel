# 散歩開始時の現在地センタリング調整

## 背景 / 事象
- 位置情報は取得できているが、散歩開始直後の地図が東京駅に固定される
- 散歩開始時点で取得できた現在地を地図中心に反映したい

## 目的
- 散歩開始直後に取得できた現在地を地図の中心として表示する
- フォールバックは現在地が取得できない場合のみ使う
