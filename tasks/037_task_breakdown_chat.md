# チャット機能のタスク分解

## 背景 / 事象
- チャット UI/Firestore 連携の仕様はあるが、実装タスクが未整理
- 画面/データ/通知の境界が曖昧で着手しづらい

## 目的
- チャット機能をスモールステップで実装できるよう、具体タスクを起票する

## 方針
- `spec/ux.md` / `spec/data-model.md` を再確認する
- 画面/UI、Firestore 読み取り、外部リンク、通知との連携を分割する

## 要件
1. チャット UI の基盤、メッセージ取得、suggest 連携を分割してタスク化する
2. 各タスクに「背景/目的/方針/要件/テスト」を記載する
3. 読み取り専用から段階的に拡張できる粒度にする
4. `tasks/PROGRESS.md` に優先順位付きで追加する
5. 仕様の不足があれば `spec/` を先に更新し、その上でタスクを起票する

## テスト
- 各タスクに検証手順が含まれていること
