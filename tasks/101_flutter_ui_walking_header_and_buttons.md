# 散歩中マップのヘッダー/ボタン UI を waking 風に調整する

## 背景
- 現状の散歩中マップ UI は、ヘッダー情報とフッターのボタン/チャット導線のデザインが暫定のままになっている
- `spec/images/waking.PNG` のような、カード型のヘッダーと下部ボタン構成に寄せたい

## ゴール
- 散歩中マップ画面で、以下の UI が waking 風の見た目で表示される
  - 画面上部に、距離（例: `2.5km`）と散歩経過時間（分）をまとめて表示する白背景のカード
  - カード右側に、出発地/現在地などを示すテキスト行が入る余白レイアウト（具体的な町名の実装は不要）
  - 画面下部中央に「散歩を終わる」ボタン（waking 画像のようなグラデーション + 角丸）
  - 画面左下に、少し透けたチャットボタン（丸型 or 角丸ボタン）を表示
  - 散歩 ID などのデバッグ用テキストは画面上に表示されない
