# 設定画面からマップ情報を確認できるようにする

## 背景 / 事象
- マップ上のアトリビューション表示を非表示にした
- 規約対応として、Settings から情報を確認できる導線が必要

## 目的
- 設定画面にマップ情報の確認導線を追加する

## 方針
- Settings に Map Info 項目を追加し、ボトムシートで提供元情報を表示する

## 要件
1. 設定画面に Map Info の導線があること
2. Map Info でテーマ別の提供元情報が確認できること

## テスト
- Map Info を開けること
- 選択中のテーマが Current 表示されること
