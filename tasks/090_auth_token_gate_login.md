# Bearer トークン未取得時にログインへ戻す

## 背景 / 事象
- FirebaseAuth の currentUser が存在しても bearer token が取得できないことがある
- トークンが無い状態で画面が進むと API 呼び出しが詰まる/失敗する

## ゴール
- bearer token が取得できない場合はログイン画面から開始する
- 取得失敗時にアプリが固まらず、ユーザーに再ログインを促せる
