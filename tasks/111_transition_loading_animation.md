# 散歩開始/終了のトランジションローディング化

## 背景
- 現在は半透明のオーバーレイでローディングを表示している
- 散歩開始/終了時に「画面が切り替わる」体験を作りたい
- ローディングが完了しても回り続けるバグがある

## ゴール
- 散歩開始/終了時にフルスクリーンのトランジションローディングを表示する
- ロゴ（簡易マーク）を回転させる
- ローディング終了後に必ず閉じる
