# iOSバックグラウンド位置更新のバックエンド取り込み

## 背景
- iOS でバックグラウンド中に位置更新が取得できず、提案リクエストが止まる
- フロントのみの対応が難しい場合に備えて、バックエンドで位置更新と提案判定を担う

## ゴール
- 位置更新取り込み API を追加する
- Firestore の位置履歴に反映される
- 条件を満たせば提案リクエスト/タスク発行が行われる
