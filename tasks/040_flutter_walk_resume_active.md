# 散歩再開（active walk 復元）と位置情報許可のガイド

## 背景 / 事象
- アプリをタスクキルすると active walk が残っていても復元されず、再開しにくい
- Locus の権限許可がエミュレータで分かりづらく「何も起きない」状態になりやすい

## 目的
- active walk を Firestore から復元し、散歩を続きから再開できるようにする
- 位置情報許可やエミュレータ利用時の案内を UI で表示する

## 方針
- `users/{uid}/walks` を `status=active` で検索し、1件あれば状態に反映
- `/v1/walks` が `WALK_ALREADY_ACTIVE` の場合は復元して Walk 画面へ遷移
- 位置情報が来ない場合のガイド文言を表示する

## 要件
1. ホーム表示時に active walk があれば状態に反映する
2. 散歩開始ボタンは active walk があれば再開扱いで遷移する
3. `WALK_ALREADY_ACTIVE` 時は復元して Walk 画面へ遷移する
4. 位置情報が更新されない場合はエミュレータでの位置指定を案内する

## テスト
- タスクキル後に散歩開始を押すと再開できること
- `WALK_ALREADY_ACTIVE` のときエラー表示ではなく再開されること
- エミュレータで location 未設定の場合にガイド文言が表示されること
