# ホーム初期位置の東京駅フォールバックと散歩開始位置の誤差修正

## 背景
- 起動直後のホーム画面が東京駅に固定される
- 散歩開始時に東京駅から現在地までの大移動として記録されることがある

## ゴール
- 散歩開始の開始地点が実際の現在地になる
- 現在地取得前のフォールバックは開始地点に使わない

## 対象範囲
- HomeScreen の現在地取得と開始地点決定ロジック

## 非対象
- マップテーマ/デザインの大幅な変更
- 位置情報のバックグラウンド動作

## ToDo
- [ ] フォールバック中心のフラグを管理し開始地点に使わない
- [ ] 現在地が取れない場合は散歩開始を中断し通知する
- [ ] 起動直後と散歩開始の挙動を確認する

## 受け入れ条件
- 散歩開始で東京駅起点の大移動が発生しない
- 現在地取得失敗時にユーザーへ通知される

## テスト
- 位置情報許可済み: 散歩開始地点が実際の現在地
- 位置情報未許可/取得中: 散歩開始がブロックされ通知が出る
