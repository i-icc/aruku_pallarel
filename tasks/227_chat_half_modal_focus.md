# チャットのハーフモーダル化とメッセージタップのマップフォーカス

## 背景
- チャットをマップ上のハーフモーダルとして表示したい
- チャット一覧のメッセージをタップしたら該当する街灯ピン位置にフォーカスしたい

## ゴール
- チャットがハーフモーダルで表示され、背面にマップが残る
- メッセージタップで該当する街灯ピンへフォーカスし、ピン選択が同期される

## 依存
- 212: 提案チャット画面を dm_chat 風に実装する
- 211: 散歩中マップに提案ピンを表示する

## 対象範囲

- チャットのハーフモーダル UI
- メッセージタップ → マップフォーカス連動

## 非対象
- チャット送信機能の追加
- 履歴画面の追加要件（必要なら別タスク）
