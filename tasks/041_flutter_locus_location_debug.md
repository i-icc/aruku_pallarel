# Locus の位置取得デバッグとエミュレータ案内

## 背景 / 事象
- エミュレータで「Enable Location」を押しても位置取得が始まらない
- 取得状態の確認が UI から分かりづらい

## 目的
- 位置情報の取得状態を UI 上で確認できるようにする
- エミュレータで位置が来ない場合の案内を強化する

## 方針
- Locus の `getState` を取得して状態表示する
- `getCurrentPosition` の失敗を UI に出す
- エミュレータで位置が未設定の場合のガイド文言を表示する

## 要件
1. 位置取得状態（enabled/isMoving/位置の有無）が UI に表示される
2. `getCurrentPosition` の失敗理由が表示される
3. エミュレータで位置が未設定の場合の案内が表示される

## テスト
- エミュレータで location 未設定時に案内が表示されること
- 位置設定後に現在地が表示されること
