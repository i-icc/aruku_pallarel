# バックグラウンド位置更新の Backend 同期エンドポイント

## 背景
- バックグラウンドで位置情報を蓄積し、復帰時に提案リクエストを送る方式が安定しない
- 位置更新時点で Backend が判定し、必要なら提案リクエストを発行したい

## ゴール
- Backend に位置更新 + 提案判定を行うエンドポイントが追加される
- バックグラウンド時はアプリがこのエンドポイントを呼び出す
- 位置履歴は従来通り Firestore に保存される

## 受け入れ条件
- バックグラウンドの位置更新で Backend 経由の保存が行われる
- 条件を満たした場合にのみ suggestion request が作成される
- 条件未達時はリクエストが作成されない
