# スクリーンクラスの肥大化解消と UI/ロジックの分離 (Task 107)

## 背景
- 現状、`WalkScreen` や `HomeScreen` に UI 定義、状態管理、ビジネスロジック（座標計算、アニメーション、権限チェック等）が混在しており、ファイルサイズが肥大化している（`WalkScreen` は 1300行超）。
- メンテナンス性向上のため、UI コンポーネントの切り出しと、ロジックの分離を行う。

## ゴール
- `WalkScreen` および `HomeScreen` のコード量を削減し、構造を簡素化する。
- 状態管理とビジネスロジックを Providers/Notifiers に寄せ、Screen は UI の組み立てに専念させる。
- 再利用可能なパーツは `widgets/` に抽出し、UI の一貫性を保つ。

- 機能的なデグレードが発生していないこと（既存の機能がそのまま動作すること）
